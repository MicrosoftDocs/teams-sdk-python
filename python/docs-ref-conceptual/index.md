# Teams SDK for Python 2.0.15

Released 8/3/2026 ([release notes](https://github.com/microsoft/teams.py/releases/tag/v2.0.15))

Report issues and explore the source on [GitHub](https://github.com/microsoft/teams.py).

## PyPI packages

| Package                                                                                  | Description                                                                                                                                                                 |
|------------------------------------------------------------------------------------------|-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| [microsoft-teams-apps](https://pypi.org/project/microsoft-teams-apps/2.0.15)             | High-level framework for building Microsoft Teams applications. Handles activity routing, authentication, and provides Microsoft Graph integration.                         |
| [microsoft-teams-api](https://pypi.org/project/microsoft-teams-api/2.0.15)               | Core API client library for Microsoft Teams Bot Framework integration. Provides HTTP clients, authentication, and typed models for Teams Bot Framework APIs.                |
| [microsoft-teams-botbuilder](https://pypi.org/project/microsoft-teams-botbuilder/2.0.15) | A package used to make the microsoft-teams-apps package backwards compatible with legacy bots built using BotBuilder.                                                       |
| [microsoft-teams-cards](https://pypi.org/project/microsoft-teams-cards/2.0.15)           | Adaptive Cards models and specialized action types for Microsoft Teams applications. Provides Pydantic-based models for creating Adaptive Cards and Teams-specific actions. |
| [microsoft-teams-common](https://pypi.org/project/microsoft-teams-common/2.0.15)         | Shared utilities including HTTP client, logging, storage, and event handling. Provides common functionality used across other Teams SDK packages.                           |
| [microsoft-teams-graph](https://pypi.org/project/microsoft-teams-graph/2.0.15)           | This package provides seamless access to Microsoft Graph APIs from Teams bots and agents built with the Microsoft Teams SDK for Python.                                     |
