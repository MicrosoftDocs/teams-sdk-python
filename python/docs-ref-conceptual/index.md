# Teams SDK for Python

**Current version: 2.0.16**, released 8/19/2026 ([release notes](https://github.com/microsoft/teams.py/releases/tag/v2.0.16))

**Preview version: 2.1.0a2**, released 8/19/2026 ([release notes](https://github.com/microsoft/teams.py/releases/tag/v2.1.0a2))

Report issues and explore the source on [GitHub](https://github.com/microsoft/teams.py).

## PyPI packages

| Package | PyPI | Description |
| --- | --- | --- |
| microsoft-teams-apps | [Current](https://pypi.org/project/microsoft-teams-apps/2.0.16/), [Preview](https://pypi.org/project/microsoft-teams-apps/2.1.0a2/) | High-level framework for building Microsoft Teams applications. Handles activity routing, authentication, and provides Microsoft Graph integration. |
| microsoft-teams-api | [Current](https://pypi.org/project/microsoft-teams-api/2.0.16/), [Preview](https://pypi.org/project/microsoft-teams-api/2.1.0a2/) | Core API client library for Microsoft Teams Bot Framework integration. Provides HTTP clients, authentication, and typed models for Teams Bot Framework APIs. |
| microsoft-teams-botbuilder | [Current](https://pypi.org/project/microsoft-teams-botbuilder/2.0.16/), [Preview](https://pypi.org/project/microsoft-teams-botbuilder/2.1.0a2/) | A package used to make the microsoft-teams-apps package backwards compatible with legacy bots built using BotBuilder. |
| microsoft-teams-cards | [Current](https://pypi.org/project/microsoft-teams-cards/2.0.16/), [Preview](https://pypi.org/project/microsoft-teams-cards/2.1.0a2/) | Adaptive Cards models and specialized action types for Microsoft Teams applications. Provides Pydantic-based models for creating Adaptive Cards and Teams-specific actions. |
| microsoft-teams-common | [Current](https://pypi.org/project/microsoft-teams-common/2.0.16/), [Preview](https://pypi.org/project/microsoft-teams-common/2.1.0a2/) | Shared utilities including HTTP client, logging, storage, and event handling. Provides common functionality used across other Teams SDK packages. |
| microsoft-teams-graph | [Current](https://pypi.org/project/microsoft-teams-graph/2.0.16/), [Preview](https://pypi.org/project/microsoft-teams-graph/2.1.0a2/) | This package provides seamless access to Microsoft Graph APIs from Teams bots and agents built with the Microsoft Teams SDK for Python. |
